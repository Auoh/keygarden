# Keygarden v0.1.0 · 键息花园

首个公开的 Windows 桌面版。你正常工作，它安静生长；不需要记按键，也不需要改变工作习惯。

## 下载

**Windows 10/11 x64 · 免安装版**

- 资源：`Keygarden-0.1.0-win64-portable.zip`（约 149.5 MB）
- 解压后进入 `Keygarden-win64`，双击 `Keygarden.exe`
- 不需要管理员权限，不会写入安装目录以外的程序文件
- 本地存档位置：`%APPDATA%\keygarden\`

## 这一版包含什么

### Mode A · 键息花园

- 右下角 220 × 280 桌面生态瓶，默认桌面层、不置顶、不抢焦点
- 5 阶段实拍生态瓶随打字生长，按键触发脉冲与孢子
- 天气、昼夜、萤火虫、雨水、池塘动画
- 浅色「晨光」与深色「苔夜」两套主题，手帐或托盘切换
- 每日「今日花园」明信片：雨型、一起亮着的时间、停顿次数、新长出的植物
- 可选窗口置顶：默认关闭，在需要盖住工作窗口时打开
- A/B 悬浮窗可拖动，位置分别记忆

### Mode B · 桌边远行

- 底部旅行风景带：雾之谷、松针坡、旧车站、风蚀原、星见湖、北岸
- 按键盘节奏赶路，停顿后扎营；路程、天气、下一站实时显示
- 两帧行走、休息、到达、雨天、营地坐姿，随状态切换
- 每日旅行明信片、纪念品与本周册
- 六个实拍风景背景；素材缺失时才回退到代码绘制

### 共同能力

- 全局键盘节奏采集：只读键类与时间，不读字符、窗口标题或剪贴板
- 不联网；数据只写本地 JSON
- 系统托盘、全局快捷键、锁屏/休眠自动暂停
- 手帐里可切换 A/B、主题、暂停、开机启动和置顶

## 安装与使用

1. 下载 zip；
2. 解压到任意目录（不要在压缩包里直接运行）；
3. 运行 `Keygarden-win64\Keygarden.exe`；
4. 首次运行在手帐里选择主题；默认浅色；
5. 切换 A/B：`Ctrl+Alt+G` 打开手帐，在 Mode B 面板点「进入桌边远行」；回到 A 点「回到键息花园」。

当前构建**没有做代码签名**，Windows SmartScreen 可能提示“未知发布者”。选择“更多信息 → 仍要运行”即可。没有安装器、没有自动更新，也没有卸载程序；删除解压目录即可移除程序，用户数据在 `%APPDATA%\keygarden\`，需要时可手动删除。

## 已知限制

- 仅支持 Windows x64；未测试 ARM。
- 浅色主题的 stage-4 生态瓶与 stage-0–3 的机位/桌面不完全一致，修复提示词已写入 `docs/asset-audit-2026-10-27.md`，素材本身尚未替换。
- B 的原始风景图是 2.35:1，运行时裁成 24:5；构图可读，但部分上下空间被裁掉。
- B 的 walk / walk-b 是两张相近的行走帧，不是严格的左右脚交替；camp-sit 内含一段木头和一个额外背包，在当前尺寸下作为营地小景使用。
- Mode C · 键盘小镇仍是 `SOON`，不在本版本内。
- 仓库当前没有 `LICENSE`，默认保留所有权利；下载和运行可用，但不构成开源许可。
